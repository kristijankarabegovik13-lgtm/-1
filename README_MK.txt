BWATCH — АНИМИРАНА ПОКАНА

1. Распакувајте го ZIP-от.
2. Во GitHub креирајте repository и прикачете ги index.html и .nojekyll директно во главната папка. Не го прикачувајте самиот ZIP.
3. Во Settings > Pages изберете Deploy from a branch, main, / (root), па Save.
4. Кога GitHub Pages ќе ја објави страницата, копирајте го прикажаниот линк и испратете го до гостите.

Поканата се отвора со копчето „Отвори ја поканата“. Оригиналната слика е вградена во HTML-фajлот. 15 украси нежно се движат горе-долу.

Музика: избраното YouTube видео https://www.youtube.com/watch?v=g-OF7KGyDis
Потребен е интернет. Некои телефони бараат дополнителен допир на ▶ во видеото. Видеото е вградено преку официјалниот YouTube плеер; нема локална MP3-копија.

За тестирање на музиката, отворете ја објавената HTTPS-страница. YouTube може да не работи при отворање на HTML-фajлот директно од компјутерот (file://).

Нема инсталација, build, дополнителни слики или пакети.
